그냥 사냥해 개인정보처리방침

Android 앱 com.witlab.justhunt · 시행일 2026년 10월 3일

withchan(이하 운영자)은 「그냥 사냥해」 Android 앱의 개인정보 처리 방식을 다음과 같이 안내합니다. 문의: withchan82@gmail.com

1. 게임 진행 정보

게임 진행, 무기·각인·강화·재화, 소리 설정, 광고 이용 횟수와 보상 거래 정보는 이용자의 기기에 저장됩니다. 앱은 회원가입·로그인을 제공하지 않으며, 운영자의 서버로 이 게임 저장 데이터를 전송하거나 기기 간 동기화하지 않습니다. 보상 거래 정보는 중복 지급을 방지하는 데 사용됩니다.

2. 광고 서비스가 처리하는 정보

앱은 Google AdMob(Google Mobile Ads SDK)과 Google User Messaging Platform(UMP)을 사용합니다. Google은 광고 제공·맞춤설정(허용되는 경우)·광고 성과 측정·진단·부정행위 방지 및 법규 준수를 위해 IP 주소(대략적인 위치 추정에 사용될 수 있음), 광고 및 앱 상호작용, 진단 정보, 광고 ID 등 기기 또는 기타 식별자를 수집·처리·공유할 수 있습니다. 동의 선택과 동의 상태는 UMP가 처리합니다. 별도의 정확한 위치 권한, 연락처, 사진, 마이크 권한은 요청하지 않습니다.

Google의 데이터 처리 및 서비스 제공 국가, 보관 기간, 관련 권리는 Google 개인정보처리방침 및 광고 SDK 데이터 공개 안내를 참고하세요. 광고 서비스 운영 과정에서 국외 서버에서 정보가 처리될 수 있습니다. 운영자가 Google이 보유한 데이터의 보관 기간을 임의로 정하거나 직접 삭제할 수는 없습니다.

3. 광고와 이용자의 선택

부활·골드 보너스 광고는 이용자가 버튼을 눌러 선택합니다. 일정 조건을 만족한 수동 마을 귀환 시에는 전면광고가 표시될 수 있습니다. 필요한 지역에서는 앱 실행 시 동의 안내가 표시됩니다. 개인정보 옵션이 요구되는 경우 게임 도움말의 ‘광고 개인정보 설정’에서 선택을 변경할 수 있습니다. Android 설정에서 광고 ID를 삭제하거나 광고 개인정보 설정을 변경할 수 있습니다. 개인 맞춤 광고 동의를 거부하더라도 제한적 또는 개인 맞춤이 아닌 광고가 표시될 수 있습니다.

4. 보관과 삭제

기기에 저장한 게임 진행은 앱 시작 화면의 ‘새 모험으로 초기화’에서 초기화할 수 있습니다. 이 기능은 게임 진행을 초기화하며 소리 설정과 SDK 동의 정보까지 모두 삭제하는 기능은 아닙니다. Android의 앱 정보 → 저장공간 → 데이터 삭제 또는 앱 제거를 이용하면 해당 앱의 로컬 데이터를 삭제할 수 있습니다. 초기화·삭제 후에는 진행을 복구하지 못할 수 있습니다. 자세한 내용은 데이터 삭제 안내를 참고하세요.

이메일 문의를 보내면 주소와 문의 내용이 문의 처리 목적으로 이메일 서비스에서 처리됩니다. 문의 내용 삭제를 원하면 같은 연락처로 요청할 수 있습니다. 보관이 필요한 사유가 있다면 처리 시 안내합니다. Google이 보유한 정보에 대한 권리는 Google의 개인정보 도구와 요청 절차를 이용해야 합니다.

5. 안전한 처리

광고 SDK는 데이터를 전송할 때 TLS를 사용합니다. 앱은 평문 HTTP 연결과 외부 웹 콘텐츠의 게임 내 로딩을 제한하며, Android 자동 백업을 사용하지 않습니다. 앱의 로컬 저장은 기기 보안 상태의 영향을 받습니다.
